## Add the extensions your System needs

### Sound

- **System 7.0 to 7.1:** install **Sound Manager 3.1** and its **Sound control panel**.
- **System 7.5 and later:** built in.

System 7.0 also needs QuickTime; see the [sound guide](../topics/sound.md#using-it).

### Shared Folder

- **System 7.0 to 7.5:** install **File System Manager 1.2**.
- **System 7.6 and later:** built in.

### Installation

Inside the classic Macintosh, drag the extensions and the Sound control panel onto the **System Folder**, let
Mac OS put them in place, then **restart**. If the shared folder isn’t available yet, bring the files in on a
mounted disk image.
